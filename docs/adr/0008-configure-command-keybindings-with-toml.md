# Configure registered Command keybindings with TOML

Virtui will load optional user-level TOML overrides that map stable, dotted Command IDs to ordered key lists, layering them over lazydocker-compatible compiled defaults. A registered Command owns its structural Command Scope and implementation, while one validated effective registry drives dispatch, contextual help, and inline hints; configuration changes bindings only, with custom Commands and shell commands deferred. TOML was chosen over YAML for predictable hand-edited syntax around punctuation-heavy keys, and the registry seam prevents customization from duplicating provider or UI behavior.
