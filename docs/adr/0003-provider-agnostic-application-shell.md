# Keep the application shell provider-agnostic

Virtui's Ratatui application shell will depend on a small provider-workspace interface rather than branching on Docker, Incus, or future provider identities. Each provider workspace owns its CLI invocation, output parsing, native resource model, supported detail views, and commands; it supplies UI-neutral resource panels and selected-resource details rather than Ratatui widgets. The shell owns the horizontal provider selector, shared navigation, focus, refresh coordination, layout, and rendering. This seam keeps provider knowledge local while allowing genuinely different provider workspaces behind the same application structure.
